# OK차트 SOAP 기록 도우미 (v9)

HTML 기반의 오프라인-동작 SOAP 작성 도우미입니다. 초진·재진·장기치료 평가, 인체도 통증부위 선택, 다빈도 증상 문진, 침술/전침/뜸/부항/약침/추나 시술기록 및 변증 기록을 지원합니다.

## 웹 배포 설정 (최초 1회)

이 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택한 다음 **main / (root) → Save**를 눌러 GitHub Pages를 활성화하세요.

사이트 주소(활성화 후): https://ehdehd756-droid.github.io/okchart-soap/

이후 `main`의 `index.html`을 업데이트하면 같은 주소에서 새 버전을 사용할 수 있습니다.

## 사용 및 개인정보 주의

- 현재 프로그램은 브라우저에서 입력을 처리하며 환자정보를 GitHub 저장소에 저장하거나 서버로 전송하도록 설계되지 않았습니다.
- 소스코드는 공개되어 있으므로 **환자 이름·주민등록번호·전화번호·진료기록을 GitHub에 업로드하지 마세요.**
- 추천 경혈, 진단·검사, EDI 코드는 참고용입니다. 실제 시행하지 않은 술기를 기록하거나 코드가 표시됐다는 이유로 청구하면 안 됩니다.
- OK차트 직접 연동은 구현되지 않았습니다. 생성된 SOAP를 확인 후 복사·붙여넣기 하세요.
